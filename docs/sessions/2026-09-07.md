### Bugs that only running it would have found

- A `<LogonTrigger>` with no `<UserId>` means "when any user logs on", which is
  machine wide and needs an elevated shell. The heartbeat's calendar trigger
  has no such distinction, which is exactly why one task registered and the
  other did not from the same prompt.
- `tts.output_format` is `pcm_24000`: headerless samples that `decodeAudioData`
  rejects outright. Voice worked in the terminal and was silent in the browser,
  and neither of the two causes predicted was right.
- `hidden` is a property of `HTMLElement`. Setting it on an `<svg>` succeeds,
  writes nothing, and changes nothing, so the mic button showed a microphone
  while it was recording.
- `_build_agent` defaulted the gate to `TerminalGate`, so a browser turn would
  have blocked forever on an `input()` nobody could see.
- The `Sec-WebSocket-Accept` constant was wrong by one character and every unit
  test passed, because they all agreed with each other and with nothing outside.
- A long running server wrote its log into an 8KB buffer nothing flushed, so
  `ui.log` was empty for exactly as long as it would have been useful.

## Where the next session starts

**Paste and file, dry run first.** The operator pastes a document into a turn
and Ranger decides which account it belongs to and files it into
`History/<Account>/YYYY-MM-DD <type> <slug>.md`. The dry run writes nothing and
exists so the matcher can be trusted before it has ever written anything.

The rules, all agreed: match on attendee email domain, then contact, then name;
more than one match is a no-match; never guess; unmatched goes to the inbox
with candidate accounts to pick from. **The account folder must be chosen from
the set of real account filenames and never composed from text in the
document**, because the document is written by strangers.

Amendment D is restated rather than relaxed: Ranger may create under `Ranger/`
and `History/`, may modify only under `Ranger/`, and may delete nothing
anywhere. The gate is on **creating a new account folder**, not on filing into
an existing one; a gate on every document would decay into a reflex within a
week, and a gate clicked without reading is worse than no gate.
